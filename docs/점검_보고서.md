# 🎤 교실 속 4채널 루퍼 — 구동 점검 및 수업 활용 보고서

- 점검 대상: `index.html` (아카펠라 메이커, 4채널 루퍼)
- 점검 일자: 2026-09-26
- 점검 방법: Chromium 헤드리스 브라우저 + 가상 마이크로 실제 구동  
  (녹음 → 재생 → 전체 재생 → WAV 다운로드 → 삭제, 데스크톱 1280px / 모바일 375px 화면)

## 1. 구동 결과 요약

| 기능 | 결과 | 비고 |
|---|---|---|
| 화면 표시 (데스크톱/모바일) | ✅ 정상 | 모바일에서 1열 배치, 가로 스크롤 없음 |
| 마이크 권한·파트별 녹음 | ✅ 정상 | `audio/webm` 녹음 |
| 파트별 재생 / 전체 동시 재생 | ✅ 동작 | 단, 반복(루프) 없음 |
| 메트로놈 | ✅ 동작 | 120BPM에서 약 500ms ± 2ms |
| WAV 다운로드 | ⚠️ 동작하나 헤더 오류 | 아래 A-5 참고 |
| 녹음 없이 다운로드 | ✅ 안내창 표시 | |
| 재생 중 삭제 | ⚠️ 미디어 오류 발생 | 아래 B-1 참고 |

전체적으로 **"4개 파트를 녹음해서 합쳐 듣는다"는 기본 흐름은 잘 동작**합니다.
다만 이름이 "루퍼"인 만큼 기대되는 **반복 재생·박자 맞추기** 기능이 빠져 있어서,
학생들이 실제로 녹음하면 파트끼리 박자가 어긋나기 쉽습니다.

## 2. 수정이 필요한 부분

### A. 수업 흐름에 직접 영향 (우선 수정 권장)

**A-1. 녹음할 때 기존 파트가 들리지 않음 (오버더빙 불가)**
- 현상: 비트박스를 녹음한 뒤 베이스를 녹음하면, 비트박스가 자동으로 재생되지 않습니다. 학생은 아무 반주 없이 녹음하게 되고, 합쳤을 때 박자가 어긋납니다.
- 제안: `녹음` 버튼을 누르면 이미 녹음된 파트를 처음부터 함께 재생하면서 녹음하도록 변경 (이어폰 착용 안내는 이미 있으므로 잘 맞습니다).

**A-2. 카운트인과 루프 길이 기준이 없음**
- 현상: 녹음 버튼을 누르는 즉시 녹음이 시작되고, 정지는 손으로 누릅니다. 실험에서 두 파트의 길이가 2.10초 / 3.00초로 제각각이었습니다. 반복(loop) 설정도 꺼져 있어 한 번 재생하고 끝납니다.
- 제안:
  - 녹음 전 "하나, 둘, 셋, 넷" 1마디 카운트인
  - BPM 기준 **2마디 / 4마디 고정 길이**로 자동 정지 → 모든 파트 길이가 같아짐
  - 전체 재생 시 무한 반복 (진짜 "루퍼")
  - 녹음 중에는 메트로놈이 계속 들리도록 연동 (현재는 `전체 동시 재생`을 누르면 메트로놈이 꺼짐)

**A-3. 마이크 음성 처리 기능이 켜져 있어 비트박스·베이스 소리가 뭉개짐**
- 현상: 실제 마이크 설정값이 `echoCancellation / noiseSuppression / autoGainControl = true`로 확인되었습니다. 통화용 설정이라 "퉁·치·킥" 같은 타격음과 저음을 소음으로 판단해 깎고, 음량을 자동으로 오르내리게 합니다.
- 제안: 이어폰 사용을 전제로 하므로 세 옵션을 끄고 요청:
  ```js
  getUserMedia({ audio: { echoCancellation: false, noiseSuppression: false, autoGainControl: false } })
  ```

**A-4. 아이패드·아이폰에서 파트별 볼륨 슬라이더가 동작하지 않음**
- 원인: iOS/iPadOS Safari는 `<audio>.volume` 값을 코드로 바꾸는 것을 허용하지 않습니다(항상 1). 현재 볼륨은 `audio.volume`으로만 조절합니다.
- 제안: 재생을 Web Audio(`AudioBufferSourceNode` + `GainNode`)로 바꾸면 볼륨이 모든 기기에서 동작하고, 4개 파트가 같은 시각에 정확히 시작되어 A-2의 루프와도 잘 맞습니다.

**A-5. WAV 파일 헤더의 데이터 크기가 40바이트 잘못 기록됨**
- 현상: 다운로드 파일 529,244바이트 중 데이터 크기가 529,240으로 기록됨 (정상값 529,200).
- 원인: `audioBufferToWav()`에서 `setUint32(length - pos - 4)` — `pos`가 0이라 계산이 틀립니다.
- 제안: `setUint32(length - 44);` 로 수정. 대부분의 플레이어는 재생되지만, 일부 편집 프로그램·기기에서 끝부분 잡음이나 오류가 날 수 있습니다.

### B. 안정성·사용성 개선

| # | 내용 | 제안 |
|---|---|---|
| B-1 | 재생 중 `삭제`하면 `src=""`로 인해 미디어 오류(코드 4) 발생, 이전 녹음의 메모리(Object URL)도 해제되지 않음 | 삭제 전 `pause()` → `removeAttribute('src')` → `load()`, `URL.revokeObjectURL()` 호출 |
| B-2 | 파형 그림이 `Math.random()`으로 그린 **가짜 막대**라서 실제 소리 크기와 무관함 (녹음이 안 되고 있어도 막대가 움직임) | `AnalyserNode`로 실제 입력 음량 표시 → 학생이 "내 소리가 들어가고 있구나"를 확인 가능 |
| B-3 | 메트로놈이 `setInterval` 기반이라 태블릿 부하·탭 전환 시 박이 밀릴 수 있고, 강박(1박) 구분이 없음 | `audioCtx.currentTime` 기준 예약 방식 + 1박 높은음 |
| B-4 | 녹음이 끝나도 마이크가 계속 켜져 있음 (브라우저 마이크 표시 유지) | 모든 녹음이 끝나면 `track.stop()` 또는 "마이크 끄기" 버튼 |
| B-5 | 새로고침하거나 탭을 닫으면 녹음이 모두 사라짐 (경고 없음) | `beforeunload` 경고 + IndexedDB 임시 저장 |
| B-6 | 녹음 중인 파트가 재생 중이어도 멈추지 않음, 같은 파트를 재녹음할 때 확인 없음 | 녹음 시작 시 해당 파트 재생 정지, 덮어쓰기 확인 |
| B-7 | `MediaRecorder` 미지원 브라우저(구형 기기)에서 스크립트 오류로 멈춤 | `typeof MediaRecorder === 'undefined'`일 때 안내 문구 표시 |
| B-8 | 탭 제목("아카펠라 메이커")과 화면 제목("교실 속 4채널 루퍼")이 다름, `Pretendard` 글꼴을 불러오지 않아 기본 글꼴로 표시됨, `정지` 버튼의 활성/비활성 색 구분이 약함 | 제목 통일, 글꼴 CDN 추가, 비활성 버튼 대비 강화 |

## 3. 즐겁고 쉬운 아카펠라 수업을 위한 아이디어 5가지

### 💡 1. 파트별 "따라 하기 가이드" + 음절 카드
- 파트마다 `예시 듣기 👂` 버튼과 **소리 나는 대로 적은 음절 카드**를 둡니다.
  - 🥁 비트박스: `북 · 치 · 기 · 치 | 북 · 북 · 치 · 기`
  - 🎸 베이스: `둠 — 둠 둠 | 둠 — 두 둠`
  - 👥 화음: `우~ / 아~` (긴 음 유지)
- 악보를 몰라도 **보고 → 듣고 → 따라 하는** 3단계로 누구나 시작할 수 있습니다.
- 수업 팁: 첫 10분은 전체가 비트박스 음절 카드를 합창하며 몸풀기.

### 💡 2. 화음이 쉬워지는 "기준음·코드 가이드"
- 화음 파트가 가장 어렵습니다. 조(C, G 등)와 코드 진행(예: C–G–Am–F)을 고르면 **녹음에 들어가지 않는 가이드 음**이 이어폰으로만 나오게 합니다.
- 화음 파트를 "높은 우~ / 낮은 우~"처럼 두 명이 나눠 부르게 하면 3도 화음을 자연스럽게 체험합니다.
- 튜너(음정 표시)를 더하면 "초록불이 되면 성공!" 같은 즉각 피드백이 가능합니다.

### 💡 3. 레이어 쌓기 릴레이 & "빠진 파트 찾기" 퀴즈
- 모둠원 4명이 비트박스 → 베이스 → 화음 → 멜로디 순서로 **4마디 루프를 한 겹씩 쌓는 릴레이**를 합니다. (A-1, A-2 수정과 연결)
- 각 파트에 `뮤트 🔇 / 솔로 🎧` 버튼을 추가하고, 발표 때 한 파트를 몰래 끈 뒤 "어떤 파트가 빠졌을까?" 퀴즈를 냅니다.
- 파트의 역할(리듬·뿌리음·화음·선율)을 귀로 구분하는 감상 활동이 자연스럽게 이뤄집니다.

### 💡 4. 박자 정확도 게임 (점수·배지)
- 메트로놈과 녹음된 비트박스의 타격 시점을 비교해 **"박자 정확도 87점 🎯"**처럼 보여 줍니다.
- 배지 예시: `박자왕 🥇`, `베이스 장인 🎸`, `화음 마스터 🌈`, `4파트 완성 🏆`.
- BPM 단계(80 → 100 → 120)를 레벨로 삼아 "레벨 업" 도전 과제로 운영하면 반복 연습 동기가 생깁니다.

### 💡 5. 모둠 발표회(갤러리) 모드
- 완성곡에 모둠 이름·곡 제목을 붙여 저장하고, 선생님 화면에서 **모둠별 카드로 모아 재생**합니다.
- 친구 모둠 작품에 스티커 투표(👏 박자 최고 / 🎵 화음 최고 / 😂 창의상)를 받는 미니 발표회를 엽니다.
- 곡 프리셋(예: `작은 별` 80BPM, `캐논 코드` 90BPM, `학교 종` 100BPM)을 제공하면 곡 고르는 시간을 줄이고 바로 활동에 들어갈 수 있습니다.

2장의 수정 사항(A-1 ~ A-5, B-1 ~ B-8)을 `index.html`에 모두 반영했습니다.

| 항목 | 반영 내용 |

| A-1 오버더빙 | 녹음 시 이미 녹음된 파트가 박자에 맞춰 함께 반복 재생됨 |
| A-2 카운트인·루프 | 1마디 카운트인 → 2/4/8마디 고정 길이 녹음 후 자동 종료, 모든 재생은 무한 반복. 녹음된 파트가 있으면 BPM·길이 잠금 |

- iOS 17 이상에서는 무음 스위치가 켜져 있어도 소리가 나도록 오디오 세션을 지정합니다.
- 검증: Chromium(가상 마이크)에서 카운트인 → 자동 종료, 오버더빙, 취소, 전체 재생·파트 켜기/끄기, 볼륨, WAV 다운로드(헤더 정상), 새로고침 후 복원, 삭제, 모바일 화면(375px)을 확인했습니다. 실제 아이패드·아이폰에서의 지연 보정과 볼륨은 기기에서 한 번 더 확인이 필요합니다.

## 6. 수업 아이디어 반영 (1번·3번)

### 💡 1. 파트별 "따라 하기 가이드" + 음절 카드
- 각 파트에 **음절 카드**(한 칸 = 8분음표, 한 마디 = 8칸)와 소리 내는 요령을 표시합니다.
  - 🥁 비트박스: `북 치 박 치 | 북 북 박 치` (모든 마디 반복)
  - 🎸 베이스: `둠 · · · 둠 · 둠 ·` — 도(C) → 파(F) → 도(C) → 솔(G)
  - 👥 화음: `우~~~~~~~` — 미 → 파 → 미 → 레
  - 🎵 멜로디: "작은 별" (반짝반짝 / 작은별 / 아름답게 / 비치네)
- **예시 듣기 👂** 버튼: 현재 BPM·길이에 맞춰 예시 소리를 합성해 들려주고, 카드의 현재 칸이 불이 들어오듯 표시됩니다. 반복 재생 중에 누르면 다음 마디 시작에 맞춰 함께 나옵니다. 예시 소리는 녹음·다운로드 음원에 들어가지 않습니다.
- 카드의 칸 표시는 **녹음 중에도** 움직이므로, 학생이 카드를 보며 박자에 맞춰 부를 수 있습니다.

### 💡 3. 레이어 쌓기 릴레이 & 빠진 파트 찾기 퀴즈
- **릴레이**: 비트박스 → 베이스 → 화음 → 멜로디 순서로 다음 녹음 차례인 파트에 점선 테두리와 "👉 다음 녹음 차례!"가 표시됩니다.
- **솔로 🎧**: 박자를 유지한 채 그 파트만 남기고 나머지를 끕니다. (재생 버튼은 파트별 켜기/끄기)
- **빠진 파트 찾기 퀴즈 🕵️** (녹음된 파트 2개 이상):
  1. 무작위로 한 파트를 뺀 채 반복 재생하고, 화면의 파트 상태는 "❓ 비밀!"로 가립니다.
  2. 학생이 빠진 파트를 고르면, 오답은 줄이 그어지고 정답이면 빠진 파트가 박자에 맞춰 다시 들어와 "전체"를 들려줍니다.
  3. 한 번에 맞힌 수와 🔥 연속 정답을 표시합니다. `다음 문제` / `퀴즈 끝내기`.
- 검증: Chromium에서 예시 재생·칸 표시, 반복 중 마디 정렬, 녹음 중 칸 표시, 릴레이 차례 표시, 솔로, 퀴즈(오답·정답·다음 문제·종료), 모바일 화면을 확인했습니다.

## 7. 수업 아이디어 반영 (2번·4번·5번) 및 저작권 표기

### 💡 2. 기준음·코드 가이드 + 음정 튜너
- **곡 선택**: 작은 별(프랑스 민요) · 환희의 송가(베토벤) · 비행기(미국 민요 「Mary Had a Little Lamb」). 녹음 전이면 곡에 맞는 BPM으로 맞춰 줍니다.

## 8. 실제 수업 사용성 개선 (직접 구동 점검)

### 점검 방법
아이패드 세로(768×1024)와 휴대폰(375~390px) 크기로 "처음 쓰는 학생"이 되어 녹음 → 다시 녹음 → 다음 파트 → 전체 재생 → 퀴즈 → 연습 → 발표회 저장 → 다음 모둠 초기화까지 전 과정을 구동했습니다.

### 발견한 불편함
| # | 불편함 | 근거 |
|---|---|---|
| 1 | 첫 화면이 선생님용 설정(BPM·곡·조·코드·튜너)으로 가득 차 녹음 버튼이 아래로 밀림 | 아이패드 첫 화면에서 녹음 버튼 위치 778px, 페이지 길이 2,399px |
| 2 | 버튼이 너무 많고 작음 | 화면의 버튼 35개, 누르기 작은(40px 미만) 조작 40개 |
| 3 | 카운트인·녹음 중 표시가 작은 글씨 한 줄이라 모둠 전체가 시작 순간을 알기 어려움 | 녹음 중 스크린샷 |
| 4 | 녹음하지 않는 다른 파트 카드까지 칸 표시가 움직여 헷갈림 | 비트박스 녹음 중 베이스 카드 표시 |
| 5 | 녹음 직후 바로 들어보거나 다시 녹음하기 어렵고, 브라우저 기본 확인창이 뜸 | 재녹음 시 `confirm()` 창 |
| 6 | 다음 모둠으로 넘어가려면 파트 4개를 하나씩 지워야 함 | 삭제 확인창 4번 |
| 7 | 처음 쓰는 학생을 위한 안내·마이크 점검이 없음 | — |
| 8 | 마이크가 막혔을 때 원인·해결 방법을 알려 주지 않음 | 알림창 한 줄 |
| 9 | 카카오톡으로 공유한 링크를 열면 앱 안 브라우저에서 녹음이 안 될 수 있음 | SNS 미리보기 추가로 카톡 공유가 예상됨 |
| 10 | 연습 중 태블릿 화면이 꺼짐, 재생 버튼이 파트마다 흩어져 있음 | — |

### 고친 내용
- **탭 구성**: 🎤 녹음실 · 🎯 연습실 · 🕵️ 퀴즈 · 🏆 발표회. 녹음실 첫 화면에는 곡 요약 한 줄, 단계 안내, 4개 파트만 남김 → 페이지 길이 1,661px, 녹음 버튼 565px(첫 화면 안), 작은 조작 2개.
- **곡·빠르기 설정 창**: 곡·조·BPM(레벨 버튼)·길이를 한곳에 모음. 잠겨 있으면 이유와 "처음부터 다시" 버튼을 함께 표시.
- **녹음 전용 화면**: 큰 글씨 "하나·둘·셋·넷" 카운트인 → "🔴 녹음 중"과 진행 막대, 마디 수, 크게 보이는 가이드 카드, 실제 마이크 입력 막대 → 결과 화면(박자 점수와 색깔 점) → [▶ 같이 들어보기] [🔁 다시 녹음] [✅ 좋아요! 다음은 ○○]. 좋아요를 누르면 다음 파트로 화면이 이동하며 반짝입니다.
- **파트 칸 단순화**: 큰 "🔴 녹음하기/🔁 다시 녹음" 버튼 + 👂 예시 듣기 · ▶ 내 녹음 · 🔊 소리 켬/끔 · 🗑️ 지우기. 소리를 끈 파트는 전체 재생·저장에서 빠짐.
- **하단 고정 재생 막대**: ▶ 전체 재생/⏹ 멈추기, ⏱️ 박자 소리, 🎹 코드 반주를 어느 탭에서나 바로. 키보드 스페이스 = 재생/멈춤, Esc = 창 닫기.
- **단계 안내 배너**: 진행 상황(🥁🎸👥🎵)과 "다음은 ○○!" 안내, 이동 버튼.
- **처음부터 다시(새 모둠)**: 녹음 전체 삭제 + 배지·모둠 이름 초기화를 한 번에(발표회 작품은 유지).
- **사용법 창**: 처음 접속 시 자동으로 열림. 이어폰 안내, 🎤 마이크 테스트(소리 막대), 녹음 순서, 저장 방법.
- **앱 안 확인 창**: 브라우저 기본 알림·확인창을 모두 앱 안의 큰 버튼 창으로 교체.
- **마이크 문제 안내**: 권한 거부 / 마이크 없음 / 다른 앱 사용 중을 구분해 해결 방법 안내.
- **카카오톡·앱 안 브라우저 안내**: 카카오톡이면 "크롬·사파리로 열기" 링크 제공.
- **태블릿 배려**: 버튼 최소 44~56px, 글씨 확대, 연습 중 화면 꺼짐 방지, 두 번 탭 확대 방지.
- **가이드 카드 표시**: 예시·녹음·재생 중인 파트의 카드만 칸 표시가 움직이도록 정리.
- **연습실**: 🔔 기준음, 🎯 튜너(큰 음 이름·바늘), "▶ 반주 틀고 연습"으로 녹음 파트와 코드 반주를 틀어 두고 지금 불러야 할 음을 표시. 탭을 떠나면 마이크·반주 자동 종료.
- **기본 빠르기**를 첫 곡(작은 별)에 맞춰 90 BPM으로 낮춤.

### 검증
Chromium(가상 마이크)으로 위 전 과정을 자동 구동해 확인했습니다: 첫 접속 사용법 창과 마이크 테스트, 설정 창, 예시 듣기(해당 카드만 표시), 카운트인 → 녹음 → 결과, 결과 화면에서 같이 듣기·다시 녹음·좋아요, 다음 파트 이동, 녹음 중 먼저 녹음한 파트 재생, 녹음 취소, 전체 재생·소리 켬/끔·내 녹음 듣기, 스페이스·Esc 키, 앱 안 확인 창, 설정 잠금, 퀴즈(탭을 떠나면 자동 종료), 연습실 반주·튜너(탭을 떠나면 마이크 종료), 발표회 저장·파일 받기·시상식·발표회 모드, 처음부터 다시, 새로고침 후 복원, 이전 버전 데이터 복원, 마이크 오류 화면, 카카오톡 안내, 휴대폰 가로 넘침 없음. 브라우저 기본 알림창은 한 번도 뜨지 않았습니다. 아이패드·아이폰 실기기 확인은 아직 필요합니다.

## 9. 아카펠라 스튜디오 (혼자 만들기 모드) — `studio.html`

수업이 아닌, 혼자서 여러 성부를 쌓아 아카펠라를 만들고 싶은 사람을 위한 별도 화면입니다. 수업 화면 오른쪽 위 **🎧 스튜디오** 버튼(또는 하단 링크)으로 들어가고, **🏫 수업 모드** 버튼으로 돌아옵니다.
